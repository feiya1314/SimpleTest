# 散户投资计划

## 策略框架

| 项目 | 内容 |
|------|------|
| **周期** | 中线（几个月到一年） |
| **流程** | 消息/政策 → 基本面验证 → 技术面择时 |
| **资金** | 8 万启动 |
| **风格** | 基本面选股 + 技术面择时 + 消息面确认 |

## 选股流程

### 1. 消息/政策来源
- 每天开盘前 15 分钟扫财联社/华尔街见闻要闻
- 盘后 10 分钟看持仓个股公告
- 关注几个靠谱的政策解读账号

### 2. 基本面验证（4 个指标）
- ROE ≥ 15%（连续 3 年）
- 营收增速 ≥ 20%（连续 2 年）
- PE < 行业均值 1.5 倍
- 资产负债率 < 60%（金融股除外）

### 3. 技术面择时
| 用途 | 周期 | 指标 |
|------|------|------|
| 定方向 | 周线 | MA20/MA60，K 线在 MA20 上方才做多 |
| 找买点 | 日线 | MACD 零轴上方金叉，或缩量回踩 MA20 不破 |
| 找卖点 | 日线 | 放量滞涨/MACD 顶背离，或跌破 MA20 |

## 仓位管理
- 单只股票 ≤ 20% 总资金
- 同时持仓 3-5 只
- 分 3 批建仓：2%试仓 → 盈利 5%加至 10% → 再加至 20%
- 永不满仓，保留至少 20% 现金

## 止损与止盈
| 规则 | 内容 |
|------|------|
| 硬止损 | -7%，无例外 |
| 移动止盈 | 盈利 +10% 时止损提到成本价；每再涨 10% 提一次 |
| 时间止损 | 买入后 3 周未达预期，减半仓观察 |
| 止盈目标 | 不预设固定止盈，用移动止损让利润奔跑 |

## 分阶段执行计划

| 阶段 | 时长 | 内容 | 资金 |
|------|------|------|------|
| **学习** | 1-2 个月 | 读《股票大作手回忆录》《笑傲股市》；学 4 个基本面指标；学均线+MACD | 不动 |
| **模拟** | 2-3 个月 | 用模拟盘跑策略，记录每一笔交易 | 仍不动 |
| **小额试错** | 3 个月 | 1-2 万实盘，严格执行止损 | 1-2 万 |
| **正式操作** | 持续 | 剩余资金按完整框架操作 | 6-7 万 |

**总时间线：6-8 个月后正式操作**

## 核心原则
1. 先活下来，再谈赚钱
2. 没有纪律，一切都是空的
3. 赚 10% 就跑、亏 30% 死扛是散户最大陷阱
4. 严格执行止损，不加仓摊平

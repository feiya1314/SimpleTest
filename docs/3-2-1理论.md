"3" —— 每天 3 小时神圣深度创造时间

- 人类大脑每天高强度创造性专注的上限约 4 小时，超过即为"垃圾时间"
- 这 3 小时必须是神圣、不可侵犯、真空的：切断一切外界联系（微信、邮件、新闻）
- 只做领域里最难、最核心、杠杆率最高的事：
  - 作家 → 只写正文，不查资料不排版
  - 程序员 → 只攻克核心算法，不修琐碎 Bug
  - 创业者 → 只思考战略和产品，不回客户消息
- 狮子式工作而非牛式工作：大部分时间休整，但出击瞬间致命
- 坚持一年深度工作 3 小时/天，产出超过 99% 混日子的打工人
- 实操建议：早起 3 小时或晚睡 3 小时，先把最宝贵时间留给自己

"2" —— 缝合两项对立技能

- 专业化是给昆虫准备的，AI 最擅长专业化，单赛道卷会被降维打击
- 真正的护城河是**"技能堆栈"**，做"缝合怪"
- 最强组合往往是一文一武/一内一外：
  - 编程 + 写作
  - 设计 + 营销
  - 心理学 + 数据分析
- 交集竞争：在 A 领域前 20% + 在 B 领域前 20% → 在"A+B"交集领域就是前 1%，甚至唯一
- Dan Koe 自身案例：设计 + 写作 + 哲学 → 黑白极简动画 + 哲学旁白 + 硬核干货的独特风格，无竞品
- 奥义：不在一个赛道卷死，去创造新赛道（差异化）

"1" —— 只解决一个核心问题

- 这个"1"就是：你曾经遇到的最大问题、踩过的最大坑
- Dan Koe 的商业帝国核心：拯救两年前那个迷茫、焦虑、没钱的自己
- 不要向外猜市场、猜用户——人心善变，市场诡谲
- 你唯一百分之百了解的人是你自己
- 你的痛 = 千万人的痛，你的弯路 = 别人的地图，你爬出的坑 = 别人的阶梯
- 把自己变成**"活体样本"**，不需要成为世界级专家，只需领先受众两步（领先太多像神，太远够不着；领先两步像学长，最听得进去）
- 好处：
  a. 永不缺灵感——生活本身就是素材库
  b. 内容极度真诚——想拉曾经的自己一把
  c. 护城河最坚固——你的痛苦和顿悟独一无二
- 不要寻找细分市场，你解决自身问题的过程和体验就是那个细分市场

# CLAUDE.md

## 项目概述

IT技术面试问答笔记库，面向中高级开发岗位（阿里、腾讯、字节等），以面试问答形式组织技术知识点。

## 文档结构

- 顶层目录按技术大类编号命名：`01-Java/`、`04-Mysql/`
- 每个大类下为主题 md 文件，编号格式：`01-主题名.md`

## 文档格式规范

- 为了让回答条理清晰需要使用分章节时，优先用## 这种子标题的形式
- 问题按 # 1. # 2. 顺序一级标题编号
- 关键的地方用 **加黑** 突出显示
- 回答中关于步骤、阶段等有序的列表必须使用1 2 3 列表展示，更有条理，例如步骤1 步骤2 或者阶段1 阶段2等根据实际来定
- 问题之间不使用 `---` 分隔
- 回答中涉及多个并列要点时，必须使用列表格式（`- `）逐条列出，不要将多项内容用分号拼接在同一行

## 回答要求
- 必须分析验证回答是否准确，不能给出错误的回复
- 如果问题下给出了参考信息，必须分析参考信息，保留参考信息的关键内容，如有图片需要保留。调整格式，去处冗余的内容。
- 如果问题下的参考信息不足以回答问题，请根据你的知识补充完问题的答案
- 回答必须保证条理清晰，并且回答内容必须详细且容易理解

## 操作约束

- 只处理 `.md` 格式文件
- 不删除已有文件（除非用户明确要求）
- 不生成测试代码、不执行编译或运行
- 新增大类时创建对应的编号目录
- 问题对应的回答要求要面向技术面试时的回答,无冗余书面语，全部可直接面试口述，但是必须保证回答内容容易理解和条理清晰

## 工作流程
1. 根据问题，分析问题，该如何回答
2. 有不清楚，请先询问
3. 根据回答要求回答问题
4. 开启子任务/子agent 做交叉验证。review回答是否正确，如果回答不正确要修正
5. 根据文档格式规范和约束写入文档

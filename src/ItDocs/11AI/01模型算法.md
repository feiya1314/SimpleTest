# 1. 人工智能的发展历程是怎样的？

- **1940s-1956（萌芽期）**：1943年麦卡洛克和皮茨提出**人工神经元数学模型**（MP模型）；1950年图灵提出**图灵测试**；1956年**达特茅斯会议**首次提出"人工智能"术语，AI正式诞生
- **1956-1974（黄金期）**：纽厄尔和西蒙开发**Logic Theorist**（第一个AI程序）；感知机提出；Eliza聊天机器人出现。科学家乐观预测"一代人内实现通用AI"
- **1974-1980（第一次寒冬）**：Lighthill报告严厉批评AI"未兑现承诺"；感知机局限性暴露；计算能力不足；政府撤资。AI研究陷入低谷
- **1980-1987（专家系统时代）**：基于规则的**专家系统**（MYCIN、XCON）取得商业成功；日本启动**第五代计算机项目**。符号主义占主导
- **1987-1993（第二次寒冬）**：专家系统天花板暴露（知识获取瓶颈、维护成本高）；Lisp机器市场崩溃；第五代项目失败。研究者回避"AI"术语
- **1993-2006（机器学习复兴）**：统计学习方法成为主流，**SVM**、**贝叶斯网络**崛起；1997年**深蓝**击败国际象棋冠军；Yann LeCun提出**LeNet-5**CNN架构
- **2006-2020（深度学习革命）**：2006年辛顿提出**深度信念网络**，深度学习概念诞生；2012年**AlexNet**在ImageNet上错误率从26%降至16%，深度学习时代开启；2016年**AlphaGo**击败李世石；2017年Google提出**Transformer**架构；2020年**GPT-3（175B）**展示惊人语言能力
- **2020-至今（大模型时代）**：ChatGPT（2022.11）2个月破1亿用户，引爆全球；GPT-4多模态超越人类基准；开源模型（LLaMA、Mistral、DeepSeek）缩小差距；**Scaling Law**和**涌现能力**成为核心范式；AI Agent、多模态融合成为新方向

# 2. 什么是机器学习？有哪些主流算法？

**机器学习**是让计算机从数据中自动学习规律和模式，并用学到的模型对新数据进行预测或决策，而非人工编写规则。

三大范式：**监督学习**（有标签）、**无监督学习**（无标签）、**强化学习**（交互+奖励）

**主流监督学习算法**：

- **线性回归**：用线性函数 y=wx+b 拟合数据，最小化误差平方和
  - 优点：简单、可解释性强、计算快
  - 缺点：只能学习线性关系、对异常值敏感
  - 适用：房价预测、销售额预测
- **逻辑回归**：线性回归加Sigmoid函数，输出 [0,1] 概率值做分类
  - 优点：实现简单、输出概率可解释
  - 缺点：决策边界线性、易欠拟合
  - 适用：垃圾邮件分类、疾病诊断、用户流失预测
- **决策树**：树形结构，内部节点是特征判断，叶节点是预测结果
  - 优点：可解释性极强、不需要特征缩放
  - 缺点：易过拟合、对数据微小变化敏感
  - 适用：信用风险评估、客户分群
- **随机森林**：Bagging代表——多棵决策树投票或取平均
  - 优点：精度高、抗过拟合、能处理高维数据、可输出特征重要性
  - 缺点：模型体积大、可解释性低于单棵树
  - 适用：金融风控、用户行为预测、Kaggle竞赛
- **SVM（支持向量机）**：寻找最大间隔超平面，用核技巧处理非线性
  - 优点：高维空间表现优秀、核技巧灵活
  - 缺点：大数据集训练慢、参数选择敏感
  - 适用：文本分类、小样本图像识别、生物信息学
- **KNN（K近邻）**：待预测样本的类别由离它最近的K个邻居投票决定
  - 优点：简单直观、无需训练、自然适应非线性
  - 缺点：预测阶段计算量大、受K值影响大、对特征缩放敏感
  - 适用：推荐系统、手写字符识别
- **朴素贝叶斯**：基于贝叶斯定理+特征条件独立性假设
  - 优点：极其简单快速、小数据集上效果好
  - 缺点：特征独立假设通常不成立
  - 适用：垃圾邮件过滤、情感分析、文本分类
- **XGBoost/LightGBM/CatBoost**：Gradient Boosting的顶级实现，逐步添加弱学习器拟合残差
  - 优点：**精度顶级**（Kaggle冠军方案）、内置正则化、特征重要性
  - 缺点：超参数多需调优、可解释性不如单棵树
  - 适用：**结构化数据分类/回归**——广告点击率、信贷评分、销量预测

**主流无监督学习算法**：

- **K-Means聚类**：将数据划分为K个簇，簇内点尽量接近
  - 优点：简单快速、适用大数据集
  - 缺点：需预先指定K值、只能找球形簇、对离群点敏感
  - 适用：客户分群、图像压缩
- **DBSCAN**：基于密度聚类，高密度区域连成簇，低密度标记为噪声
  - 优点：**不需要指定K**、发现任意形状簇、识别噪声
  - 缺点：对密度参数敏感、高维数据表现差
  - 适用：空间数据聚类、异常检测
- **PCA（主成分分析）**：线性降维，将数据投影到方差最大的方向
  - 优点：降低维度减少计算量、去除噪音、可视化高维数据
  - 缺点：降维后特征不可解释、丢失非线性结构
  - 适用：高维数据可视化、特征压缩、加速下游模型

**算法选择速查**：结构化数据最高精度选**XGBoost/LightGBM**；需要解释选**决策树/逻辑回归**；大数据非结构化任务选**深度学习**；小数据（<1000条）选**SVM/朴素贝叶斯**；发现分组选**K-Means/DBSCAN**

# 3. 监督学习和无监督学习区别？

**监督学习**：训练数据包含输入和对应的**标签**（正确答案），模型学习从输入到输出的映射关系，目标是预测新输入的输出。好比学生做题有标准答案对照。

**无监督学习**：训练数据**没有标签**，模型自行发现数据中的结构、分布或模式，目标是探索数据的隐藏规律。好比没人告诉你分类规则，自己找相似物品分组。

**核心区别**：

| 维度 | 监督学习 | 无监督学习 |
| --- | --- | --- |
| **数据** | 有标签（输入x，输出y） | 无标签（仅输入x） |
| **目标** | 预测/分类/回归 | 发现结构/聚类/降维 |
| **评价方式** | 准确率、F1、RMSE等客观指标 | 轮廓系数、紧密度等相对指标，无绝对标准 |
| **典型算法** | 线性回归、逻辑回归、决策树、SVM、随机森林、XGBoost | K-Means、DBSCAN、PCA、t-SNE、自编码器、高斯混合模型 |
| **典型场景** | 房价预测、垃圾邮件分类、图像识别、医疗诊断 | 客户分群、异常检测、高维可视化、数据压缩 |
| **复杂程度** | 需人工标注成本（数据获取门槛高） | 无需标注，但结果解读和评估困难 |

**选择依据**：

- 有标签且标注成本可接受 → 监督学习（精度更高）；
- 无标签或标签成本过高 → 无监督学习；
- **半监督学习**（少量标签+大量无标签）和**自监督学习**（自己构造标签）是两者的折中方案

# 4. 什么是深度学习？有哪些主流算法？

**深度学习**是使用多层神经网络自动学习数据的分层特征表示，从低级特征（边缘）→中级特征（形状）→高级语义（物体/概念），实现端到端学习。

和传统ML的区别在于：**特征自动学习**（无需人工设计）、需要**大量数据**、需要**GPU**、可解释性较差但复杂任务性能更高

**CNN（卷积神经网络）**：

原理：模拟视觉皮层——卷积核在输入上滑动提取局部特征，池化层降采样，逐层提取从低级到高级的特征

- 核心组件：**卷积层**（局部连接+权值共享）、**池化层**（降采样）、**全连接层**
- 经典架构演进：
  - **LeNet-5**（1998）：最早CNN，手写数字识别
  - **AlexNet**（2012）：ReLU+Dropout+GPU并行，**引爆深度学习革命**
  - **VGGNet**（2014）：全部用3×3小卷积核堆叠，深而简洁
  - **GoogLeNet/Inception**（2014）：Inception模块多尺度卷积并行+1×1降维
  - **ResNet**（2015）：**残差连接**（Skip Connection）解决梯度消失，网络可达152层+
  - **DenseNet**（2017）：密集连接，极致特征复用
  - **MobileNet**（2017）：深度可分离卷积，移动端轻量化
- 优点：**参数效率高**（权值共享）、平移不变性、局部特征提取强、并行度高
- 缺点：感受野需要堆叠扩大、对旋转无天然不变性、长距离依赖捕捉弱
- 适用：**图像分类**、目标检测（YOLO/Faster R-CNN）、图像分割（U-Net/Mask R-CNN）、人脸识别、医学影像、自动驾驶

**RNN/LSTM（循环神经网络）**：

原理：通过隐状态在时间步之间传递信息处理序列数据

- LSTM引入**遗忘门、输入门、输出门**解决长期依赖问题
- 优点：天然适合**序列数据**（文本、音频、时间序列），可处理变长输入
- 缺点：**无法并行**训练慢、长序列仍有梯度问题、自回归不能同时看上下文
- 现状：NLP领域已被**Transformer全面替代**，Transformer训练快千倍、支持长程依赖（128K+ tokens）、支持Scaling Law规模化。但在**轻量级时序预测**（IoT/边缘设备）、**实时流式语音处理**（低延迟要求）、**生产遗留系统维护**中仍有使用

**Transformer**：

原理：**彻底抛弃RNN循环结构**，完全基于**注意力机制（Self-Attention）**，通过并行计算所有位置的注意力权重捕捉全局依赖

核心创新：

- **Self-Attention**：每个词关注序列中所有其他词
- **Multi-Head Attention**：多头并行学习不同类型注意力
- **并行计算**：所有位置同时计算，速度远超RNN
- **位置编码**：用位置编码替代RNN的序列顺序

三大架构流派：

- **编码器架构**（BERT家族）：双向注意力，适用于文本理解、分类、NER
- **解码器架构**（GPT家族）：**因果注意力**（只看前面），适用于文本生成、对话、代码。GPT-3（175B）验证了Scaling Law；ChatGPT引爆全球；LLaMA/DeepSeek代表开源阵营
- **编码器-解码器架构**（T5/BART）：适用于翻译、摘要等序列到序列任务
- 优点：**并行计算**、**全局感受野**、长距离依赖极强、可扩展性强（Scaling Law）
- 缺点：**计算复杂度O(n²)**、训练成本极高、推理延迟高、需要海量数据、存在幻觉
- 适用：对话系统、文本生成、翻译、摘要、代码生成、多模态、蛋白质预测、AI Agent

**GAN（生成对抗网络）**：

原理：两个网络互相博弈——**生成器**制造假数据，**判别器**区分真假，两者在对抗中共同进步

- 经典架构：**DCGAN**（CNN标准化GAN训练）、**Conditional GAN**（条件控制生成）、**Pix2Pix**（配对图像翻译）、**CycleGAN**（非配对图像翻译）、**StyleGAN**（风格解耦，人脸生成王者）
- 优点：生成图像逼真、无需显式建模概率分布、**单次推理快**（适合实时）
- 缺点：**训练极不稳定**（需要精心平衡G和D）、**模式坍塌**（只生成少数样本）、调参地狱
- 现状：图像生成领域已被**扩散模型全面取代**。GAN在2022年之前是主流，之后全面让位给扩散模型。GAN目前仅存于**极低延迟视频生成**（高帧率）和**对抗样本/鲁棒性研究**中

**扩散模型（Diffusion Models）**：

原理：前向过程逐步向数据添加噪声到纯噪声，反向过程学习从噪声中逐步去噪恢复数据。类比——不是让一个人一步画出一幅完美油画（GAN），而是让一个人从泥巴中一点点雕刻出来，每一步只做微小修正

- **为什么能取代GAN**：核心区别在生成策略。GAN**一步对抗生成**，生成器直接一把生成图片，判别器判断真假，两者对抗训练找纳什均衡——**目标函数复杂、不稳定、易模式崩溃**。扩散模型**分步去噪生成**，从纯噪声一步一步反向去噪，每步只预测一个很小的噪声残差——**目标函数简单（L2预测噪声）、训练稳定、数学可解释（有严格变分下界推导）、覆盖完整数据分布**。代价是**采样速度慢**（需多步迭代）
- **Stable Diffusion的架构（Latent Diffusion Model, LDM）**：在**潜在空间**做扩散而非像素空间。先用**VAE编码器**将图片压缩到低维潜在空间，再在潜在空间中执行加噪→去噪。去噪主干是**U-Net（CNN架构）**，用**Cross-Attention**引入**CLIP文本编码器**的条件控制。因此SD是混合体——扩散模型为主体，CNN（U-Net）去噪，Transformer（Cross-Attention+CLIP）做条件控制
- 代表模型：**DDPM**（理论基础）、**DDIM**（加速采样）、**Stable Diffusion SD1.5/SDXL**（最广泛使用的开源文生图）、**SD3**（用DiT替代U-Net）、**FLUX**（当前顶级文生图质量）、**DALL-E 3**（闭源，文本理解强）、**Midjourney**（美学风格最突出）、**Sora**（文生视频扩散Transformer）、**DiT**（用Transformer做扩散去噪的新范式）
- 优点：图像质量最优（超越GAN）、训练稳定、灵活的条件控制
- 缺点：**采样速度慢**（需多步迭代去噪）、计算资源消耗大
- 适用：文生图、文生视频、图像编辑、3D生成、音频生成、分子结构生成

**强化学习（Deep RL）**：

原理：智能体与环境交互获取奖励，通过最大化累积奖励学习策略

- 代表算法：**DQN**（Atari游戏）、**PPO**（最稳定常用）、**AlphaGo/AlphaZero**（自对弈）、**RLHF**（ChatGPT核心技术）
- 适用：游戏AI、机器人控制、自动驾驶、量化交易、LLM对齐

**深度学习算法选择速查**：图像分类/检测/分割选**CNN**（ResNet/YOLO/U-Net）；文本理解/生成选**Transformer**（BERT/GPT）；图像生成（高质量）选**扩散模型**（Stable Diffusion）；图像生成（低延迟）选**GAN**；游戏/控制选**强化学习**（PPO）；少数据场景用**迁移学习/微调预训练模型**

# 5. 机器学习和深度学习的区别和联系？

**联系**：深度学习是机器学习的**子集**。两者核心目标相同——从数据中发现输入到输出的映射规律；都依赖**数据驱动**；共享过拟合/欠拟合、偏差-方差权衡、损失函数（交叉熵/MSE）、优化器（SGD/Adam）等底层原理

**核心区别**：

| 维度 | 传统ML | 深度学习 |
| --- | --- | --- |
| **特征工程** | **人工设计**，耗时需专家 | **自动分层学习**，端到端 |
| **数据需求** | 少（几百条即可） | 多（万级以上，越多越好） |
| **计算资源** | CPU即可 | GPU/TPU必须 |
| **训练时间** | 秒到小时 | 小时到周 |
| **可解释性** | ✅ 高（透明） | ❌ 低（黑箱） |
| **模型大小** | KB\~MB | MB\~GB/TB |
| **表格数据** | ✅ **最强**（XGBoost） | ⚠️ 弱 |
| **图像/文本/音频** | ❌ 弱 | ✅ **最强** |
| **迁移学习** | ❌ 弱 | ✅ 强（预训练+微调） |

- **本质区别在特征工程**：传统ML需要领域专家手动提取特征；深度学习通过多层网络自动从原始数据中学习分层特征（底层边缘→中层形状→高层语义）
- **数据量决定胜负**：小数据时传统ML更好（参数少，归纳偏置强）；数据量足够大时深度学习的**Scaling Law**优势显现，能力持续提升
- **并不是非此即彼**：工业界最佳实践通常是**混合使用**——推荐系统中用XGBoost处理结构化特征+深度学习处理高维稀疏特征；自动驾驶中用CNN做感知+传统规则做决策

# 6. CNN的原理是什么？有哪些经典架构？

**原理**：CNN通过三个核心思想解决传统全连接网络处理图像的参数量爆炸问题

- **局部连接**：每个神经元只连接输入的一小片区域（感受野），而非所有像素
- **权值共享**：同一个卷积核在图像的所有位置共享参数。以224×224×3图像为例，全连接第一层64个神经元需960万参数，而CNN的3×3卷积核只用1728参数——**减少了5555倍**
- **池化**：降采样（如2×2最大池化减少75%参数量），提供**平移不变性**，扩大感受野

**标准前向传播流程**：输入图像→卷积层（提取局部特征）→激活函数ReLU（引入非线性）→池化层（降采样）→重复若干次→全局平均池化/Flatten→全连接层→Softmax分类

**经典架构演进**：

- **LeNet-5**（1998）：开山之作，手写数字识别
- **AlexNet**（2012）：ReLU+Dropout+GPU并行，ImageNet错误率从26%降至16%，**引爆深度学习革命**
- **VGGNet**（2014）：全部用3×3小卷积核堆叠，结构规则整齐。两个3×3=一个5×5（参数量少28%）
- **GoogLeNet/Inception**（2014）：Inception模块多尺度卷积并行+1×1卷积降维，参数仅500万（AlexNet的1/12）
- **ResNet**（2015）：核心创新**残差连接**F(x)+x，解决深层网络退化问题（56层比20层还差）。反向传播时恒等映射保证梯度至少为1，梯度永不消失。可达152层，ImageNet Top-5错误率降至3.57%（**超越人类水平**）
- **DenseNet**（2017）：每一层与所有前面层通道拼接，极致特征复用，参数更少
- **MobileNet**（2017）：**深度可分离卷积**，计算量约标准卷积的1/8，适合移动端
- **EfficientNet**（2019）：复合缩放（深度×宽度×分辨率），精度+效率最优

**应用架构**：目标检测（**YOLO**单阶段极快、Faster R-CNN两阶段更准）；图像分割（**U-Net**编码器-解码器+跳跃连接；Mask R-CNN实例分割）

# 7. CNN 逐层提取从低级到高级的特征？为什么这样能提取到特征？

CNN 的层次结构对应了**从局部到全局、从具体到抽象**的信息聚合过程。

**底层（浅层）**：卷积核尺寸小（如 3×3），感受野仅覆盖几个像素，只能检测到**低级视觉基元**——水平/垂直/对角边缘、颜色块、亮度变化。这些是所有图像共有的基础模式，不包含语义信息。

**中层**：底层输出的边缘/色块组合成更大的局部模式。通过堆叠卷积，感受野扩大到几十像素，可以检测到**部件级模式**——眼睛形状、嘴巴轮廓、鼻子、圆弧、纹理。模型在前一层检测到的边缘基础上做组装。

**高层**：感受野覆盖大部分甚至整个图像，多层的部件组合检测到**完整语义概念**——整张人脸、汽车轮子、窗户。最后一层分类器在这些高层特征上做决策。

**为什么能提取到特征**：核心原因是**端到端学习 + 反向传播**。没有任何人告诉模型"边缘很重要"，而是通过反向传播自动涌现的：

- 训练时损失函数衡量分类错误，反向传播计算每个卷积核参数对错误的贡献
- 如果一个卷积核检测到边缘→有助于降低分类错误→梯度更新增强该卷积核的权重→该卷积核变得更敏感于边缘
- 迭代数百万次后，网络自动涌现出从边缘到语义的分层特征——是**优化目标的自然结果**

**一句话总结**：CNN 通过卷积核的**局部连接 + 权值共享**高效扫描图像，每层在前一层基础上组合更大、更抽象的模式；反向传播确保这些组合方向是朝着**分类正确率最高**的方向演进的，而非人为设计。

# 8. 生成对抗网络（GAN）的原理是什么？有哪些经典架构？

**原理**：两个网络互相博弈——**生成器（G）** 将随机噪声映射为假数据，**判别器（D）** 区分真实数据和假数据。训练目标是**Minimax博弈**：

`min_G max_D V(D,G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]`

理论上收敛到**纳什均衡**：D无法区分真假（50%准确率），G生成的数据与真实数据分布一致

**训练难点**：

- **模式坍塌（最大难题）**：G只学少数样本类型，多样性差
- 损失震荡：G和D的loss此消彼长
- 梯度消失：D太强时G的梯度趋近0
- 超参数极其敏感

**经典架构**：

- **DCGAN**（2015）：用CNN标准化GAN训练，转置卷积上采样+BN+LeakyReLU+Adam优化器
- **Conditional GAN**（cGAN）：给G和D加条件（标签/文本），实现可控生成
- **Pix2Pix**（2017）：U-Net生成器+PatchGAN判别器，配对图像翻译（草图→照片），使用cGAN loss+L1 loss
- **CycleGAN**（2017）：**循环一致性损失**，无需配对数据。两个生成器G:X→Y和F:Y→X，要求F(G(x))≈x（循环回来一致）
- **StyleGAN**（2019）：映射网络将噪声转为风格向量w，注入生成器不同层。**风格解耦**——粗层控制姿态脸型、中层控制五官比例、细层控制纹理。可以独立调整"表情"和"年龄"，可以进行平滑插值
- **BigGAN**（2018）：大规模batch size（2048）+谱范数+截断技巧，在ImageNet 1000类上生成高质量图像

**现状**：GAN在图像生成领域已被**扩散模型**大幅超越。GAN仍用于**实时生成**（单次推理快，扩散需多步去噪）和特定场景

# 9. Transformer 的原理是什么？有哪些架构流派？

**原理**：**彻底抛弃RNN循环结构**，完全基于注意力机制。核心计算是**Scaled Dot-Product Attention**：

`Attention(Q,K,V) = softmax(QK^T/√d_k)V`

**QKV的直观理解**：Attention让模型在生成每个输出时能"回头看"输入序列中的所有位置，动态决定哪些位置更重要。类比——不是像RNN一样边读边忘，而是把所有页面摊在桌上，写总结时随时翻到相关段落

- **Q（Query，查询）** = 当前位置要问什么（比如当前要翻译的词）
- **K（Key，键）** = 输入序列中每个位置有什么信息可以提供
- **V（Value，值）** = 输入序列中每个位置的实际内容
- Q和K算相似度（点积）→ 得到注意力权重（Softmax归一化）→ 权重对V加权求和 → 模型"注意"到的信息
- **√d_k缩放因子**：防止内积过大导致Softmax落入梯度饱和区

**为什么要多头**？一个注意力头只能捕捉一种关系模式（如语法关系），**多头并行**可同时捕捉语法、指代、语义、位置等多种不同类型的关联。好比多个视角同时理解一句话

**完整架构**：输入嵌入+位置编码→N层编码器（自注意力+FFN+残差+层归一化）×N层解码器（自注意力+交叉注意力+FFN）→线性层+Softmax输出

**位置编码**：用不同频率的正弦/余弦波为每个位置生成唯一编码，模型从中学到相对位置关系。因为Transformer没有RNN的顺序结构，需要用位置编码告诉模型"第3个词在第1个词后面"

**RNN vs Transformer 全面对比**：

| 维度 | RNN | Transformer（Self-Attention） |
| --- | --- | --- |
| **并行计算** | ✗ 必须串行，t时刻依赖t-1 | ✓ **所有位置同时计算**，GPU充分并行 |
| **长程依赖** | ✗ 序列长→梯度消失/爆炸，记不住 | ✓ **任意位置直接相连**，O(1)路径长度 |
| **信息表示** | ✗ 一个固定向量塞所有历史信息→信息瓶颈 | ✓ 每个位置独立表示，**信息不压缩** |
| **距离建模** | ✗ 越远越弱 | ✓ 无论远近等权访问 |
| **可解释性** | ✗ 隐藏状态难解读 | ✓ 注意力权重可直接看哪些词被关注 |
| **计算复杂度** | O(n)（串行） | O(n²)（但可并行，实际快得多） |
| **位置信息** | ✅ 天然有（按顺序读） | ⚠️ 需要额外加Positional Encoding |
| **训练速度(n=1024)** | 串行×1024步 | 一次矩阵乘法完成，**快千倍** |

**为什么Transformer能彻底替代RNN**：核心原因不是"Attention更聪明"，而是RNN的串行结构天然无法并行化，面对大算力时代被碾压。Transformer的并行计算让训练快几个数量级（n=1024时快千倍），长程依赖直接可达（RNN超过100步基本失效，Transformer可处理128K+），信息不压缩（RNN必须把所有历史塞进一个固定向量→信息瓶颈）。这三个特性共同使Transformer成为唯一能支持**规模化**（Scaling Law）的序列架构

**三大架构流派**：

- **编码器架构（BERT家族）**：**双向注意力**，每个词可见序列所有词。预训练任务为**掩码语言模型（MLM）**。代表：BERT（2018，刷新11项NLP记录）、RoBERTa、DeBERTa。适用：文本分类、NER、关系抽取、阅读理解
- **解码器架构（GPT家族）**：**因果注意力**，每个词只能看到自己和前面词。预训练为**下一个token预测**。推理时自回归生成。GPT-3（175B，2020）验证**Scaling Law**和**零样本能力涌现**；ChatGPT（2022.11）引爆全球；GPT-4（2023）多模态通过众多人类考试；开源阵营LLaMA/Mistral/DeepSeek/千问持续追赶。适用：对话、文本生成、代码、问答、Agent
- **编码器-解码器架构**：编码器双向理解+解码器自回归生成。代表：T5（把所有任务统一定义为文本到文本）、BART。适用：翻译、摘要

**高效变体**：标准自注意力复杂度O(n²)，序列长时不可接受。改进方向包括**滑动窗口+全局token**（Longformer/BigBird）、**LSH哈希分组**（Reformer）、**硬件感知显存优化**（FlashAttention）、**分布式环通信**（Ring Attention支持100万+token）

**从Transformer到多模态**：**ViT**（Vision Transformer，2020）将图像切成patch作为token输入标准Transformer编码器，在大数据上超越CNN；**CLIP**（2021）文本+图像联合训练，实现零样本图像分类；多模态大模型（LLaVA、GPT-4V、Gemini）实现图文音视频统一理解

# 10. CNN、GAN、Transformer、扩散模型有什么区别和联系？

**本质对比**：

| 维度 | CNN | GAN | Transformer | 扩散模型 |
| --- | --- | --- | --- | --- |
| **本质** | 特征提取器 | 生成模型（对抗博弈） | 序列建模器（注意力机制） | **生成框架/范式**（非基础架构） |
| **核心操作** | 卷积（局部加权求和） | 对抗训练（G vs D） | 注意力（全局加权求和） | **加噪→去噪**（分步生成） |
| **感受野** | 局部（需堆叠扩大） | — | **全局**（一次看到所有） | — |
| **并行能力** | ✅ 高度并行 | ✅ G/D内部可并行 | ✅ 训练时完全并行 | ✅ 可并行 |
| **训练难度** | 🟢 易（标准监督） | 🔴 **极难**（对抗平衡） | 🟡 中（需大量数据） | 🟢 **易**（L2预测噪声） |
| **数据效率** | 🟢 中等 | 🟡 依赖任务 | 🔴 需海量数据 | 🟡 中 |
| **推理延迟** | 🟢 极低 | 🟢 极低（一次推理） | 🟡 中到高 | 🔴 **高**（多步去噪） |
| **生成质量** | ❌ 不适合生成 | 🟡 中（模式崩溃风险） | ❌ 非生成模型 | 🟢 **最优** |
| **稳定性** | 🟢 稳定 | 🔴 **极不稳定** | 🟡 中 | 🟢 **稳定** |

**本质区别**：

- **CNN**是**局部特征之王**——参数效率高（权值共享+池化），平移不变性强，适合资源受限的感知任务
- **Transformer**是**通用智能架构**——全局建模一步到位，可扩展性强（Scaling Law），是大模型的基石
- **GAN**是**对抗生成先驱**——一步生成快但训练不稳定，已被扩散模型全面取代
- **扩散模型**是**生成质量之王**——分步去噪稳定且质量高，但推理慢。它不是独立基础架构，而是一个生成框架，去噪主干可以用**CNN（U-Net）** 或**Transformer（DiT）**

**特别说明——扩散模型与CNN/Transformer的关系**：扩散模型不是和CNN/Transformer并列的基础架构，而是**生成流程的范式**。它的去噪引擎可以是CNN（Stable Diffusion用U-Net），也可以是Transformer（SD3/FLUX/Sora用DiT）。如同汽车发动机和车身的关系——发动机可以用汽油或电动，车身可以是SUV或跑车。

**CNN/Transformer在扩散模型中扮演的角色**：

| 模型 | CNN角色 | Transformer角色 |
| --- | --- | --- |
| **Stable Diffusion (SD1.5/SDXL)** | U-Net（去噪主干） | Cross-Attention（文本控制）+ CLIP（文本编码） |
| **DiT (Diffusion Transformer)** | 不用CNN | **直接替代U-Net**，纯Transformer做去噪 |
| **SD3 / FLUX** | 不用CNN | DiT架构，Transformer做扩散引擎 |
| **Sora（视频扩散）** | 不用CNN | DiT架构处理时空Patch |
| **趋势** | CNN在扩散中逐渐被取代 | Transformer成为扩散引擎新主流 |

**四者联系**：

- **CNN+Transformer融合**：CNN做粗提取+Transformer做精细推理，如**DETR**（ResNet+Transformer检测）、**Swin Transformer**（层级窗口注意力）、**ConvNeXt**（借鉴Transformer设计理念优化CNN）
- **Transformer+扩散融合**：**DiT**（Diffusion Transformer）用Transformer完全替代U-Net做扩散去噪，**Sora**用DiT做视频生成，**SD3/FLUX**也改用DiT架构
- **四者可组合**：文生图完整链路——Transformer（CLIP）理解文本→CNN（U-Net）或Transformer（DiT）做扩散去噪→VAE解码器还原图像

**适用场景决策**：

- **CNN**：图片分类/检测/分割、移动端/嵌入式（轻量）、实时推理（<10ms）、医学影像、自动驾驶感知
- **Transformer**：所有NLP任务、大语言模型、多模态理解、代码生成、长序列建模、AI Agent
- **GAN**：极低延迟视频生成、对抗样本研究、生产遗留系统维护（新项目不推荐）
- **扩散模型**：文生图、文生视频、图像编辑/修复/超分、3D生成、音频生成

**具体场景→模型选型速查**：

| 你想做什么 | 选谁 |
| --- | --- |
| 把猫图片分类 | CNN（ResNet/ConvNeXt） |
| 写文章/大模型对话 | Transformer（GPT/LLaMA） |
| 生成一张不存在的美女图 | 扩散模型（Stable Diffusion/FLUX） |
| 手机上实时检测障碍物 | CNN（MobileNet/YOLO-nano） |
| 分析股票价格序列 | Transformer（TimeSformer） |
| 修复一张老照片 | 扩散模型（SD Inpainting） |
| 训练100B参数大模型 | Transformer（GPT架构） |
| 边缘设备做语义分割 | CNN（MobileNet+DeepLab） |
| 实时视频换脸（低延迟） | GAN（极少场景保留） |
| 语音识别/流式处理 | 小模型可用RNN，大模型用Transformer |

**一句话总结**：CNN是**感知落地首选**，Transformer是**通用智能基石**，扩散模型是**生成质量巅峰**，GAN已是**历史产物**。实际最强方案是CNN+Transformer+扩散的组合使用。

# 11. 什么是推理大模型和非推理大模型？有什么区别？

**推理大模型**：在内部生成推理链条、自我纠错、验证答案后才输出最终结果。类比人类"System 2（慢思考）"——仔细计算27×38而非直接回答
**非推理大模型**：看到问题直接凭"直觉"（一次前向传播）生成答案。类比人类"System 1（快思考）"——直接回答2+2

**核心区别**：

| 维度 | 非推理模型 | 推理模型 |
| --- | --- | --- |
| **回答方式** | 直接输出 | 先内部推理，后输出答案 |
| **自我纠错** | ❌ 不能 | ✅ 能（回溯、验证） |
| **响应速度** | 🟢 快（秒级） | 🔴 慢（几秒到几分钟） |
| **复杂推理** | 🔴 差（直觉式） | 🟢 **极强**（深思式） |
| **简单任务** | 🟢 高效 | 🔴 浪费（杀鸡用牛刀） |
| **总成本（复杂）** | 🔴 可能多次尝试 | 🟢 一次搞定更省钱 |
| **可解释性** | 🔴 黑箱回答 | 🟢 可查看推理过程 |
| **数学能力（AIME）** | \~10-16% | \~70-87%（质的飞跃） |
| **编程能力** | 🟡 中 | 🟢 强 |
| **创造性** | 🟢 好 | 🟡 可能"过度思考" |

**代表模型**：非推理——GPT-4o、Claude 3.5 Sonnet、LLaMA 3、Qwen 2.5；推理——**OpenAI o1/o3**（首个推理大模型，2024）、**DeepSeek-R1**（开源推理模型，2025，通过纯强化学习涌现推理能力）、Gemini 2.5 Pro

**推理能力从何而来**？核心是**思维链（Chain-of-Thought）**。DeepSeek-R1训练中通过强化学习，模型**自发涌现**出回溯（发现当前路径错误回到分歧点）、验证（得到答案后反过来验证正确性）、子问题分解（大问题拆小）、多路径探索（尝试多个解法）和反思（分析自己为什么错了）等策略——这些不是显式编程的，而是从RL奖励信号中自我进化出来的

**最佳实践**：**两者互补而非替代**。简单问答/翻译/创意写作用非推理模型（更快更便宜）；复杂数学/竞赛编程/科学推理用推理模型。最聪明的做法是**路由系统自动分配**

# 12. 大语言模型和 Transformer 是什么关系？

**一句话**：**Transformer是大模型的"发动机"，大模型是Transformer的"终极形态"。** 所有现代大语言模型（GPT、Claude、DeepSeek、LLaMA）的底层架构都是Transformer

**核心关系**：没有Transformer就没有大模型。2017年前主流NLP用RNN/LSTM，参数量百万级，RNN的顺序计算无法并行且长序列梯度消失，根本上限制了规模。Transformer的**并行计算**能力使训练超大规模模型成为可能

**为什么Transformer能成为大模型的基石（五大原因）**：

- **1. 并行计算=规模化的前提**：RNN的串行特性决定了训练时间O(n)，扩展到百亿级参数时成本天文数字。Transformer的Self-Attention一次矩阵乘法处理整个序列，GPU利用率拉满。**没有并行就没有Scaling Law**
- **2. Scaling Law成立**：实验证明Transformer的loss随参数/数据/算力幂次下降，**可预测地变强**。RNN/LSTM的loss会先下降然后饱和，加参数没用。Transformer是第一个"增加算力就能稳定变好"的架构，这是大模型工业化的基石
- **3. 上下文长度的自然扩展**：RNN理论无限但实际100-200步就废；原始Transformer 512；GPT-4达128K；Gemini达1M。Transformer通过工程优化（Flash Attention、稀疏注意力、Ring Attention）不断拉长上下文，**RNN架构做不到**
- **4. 架构统一了模态**：Transformer不挑食——文本（GPT）、图像（ViT）、语音（Whisper）、视频（Sora）、多模态（CLIP/GPT-4V）。**同一个架构处理所有模态**意味着跨模态融合天然可行，RNN做不到
- **5. 硬件生态已经锁定**：GPU的Tensor Core就是为矩阵乘法优化的。Transformer的训练=大量矩阵乘法→硬件利用率极高。NVIDIA的cuDNN、Flash Attention都是专为Transformer优化的。RNN的小步循环运算完全不适合GPU架构

**大模型 = 超级大的Transformer解码器**。GPT系列本质上就是把Transformer解码器堆得极大极深加上一些改进。原始Transformer（2017）只有6层编码器+6层解码器，65M参数；LLaMA-3 70B有80层解码器+8192隐藏维度+8192×28672的FFN，720亿参数

**大模型对Transformer的改进**：

- **解码器取代编码器-解码器**：GPT证明只用解码器即可完成所有任务
- **注意力机制进化**：标准注意力→因果注意力→GQA/MQA（节省KV Cache）→FlashAttention（显存优化）
- **激活函数进化**：ReLU→GELU→**SwiGLU**（LLaMA使用，效果最好）
- **位置编码进化**：绝对位置编码（sin/cos）→**RoPE（旋转位置编码）**，可外推到更长序列
- **归一化改进**：Post-Norm→Pre-Norm（训练更稳定）、LayerNorm→**RMSNorm**（计算更快）
- **MoE（混合专家）架构**：传统Transformer所有参数参与所有计算；MoE只激活一部分专家，如Mixtral 8×7B总参数46.7B每次只用12.9B，DeepSeek V2/V3也是稀疏MoE

**涌现能力**：小型Transformer只有基础语言建模能力；中型Transformer（1B-10B）增加翻译和摘要能力；大型Transformer（>10B）增加多步推理和代码生成；**大模型（>100B）突然出现**零样本推理、上下文学习、思维链、指令遵循等能力——这些是Transformer原始架构没有的，是**规模放大带来的质的飞跃**

# 13. 模型的参数（如72B）指的是什么？为什么模型文件只存参数？推理时用参数为什么能得到结果？

**参数 = 模型内部的可调节旋钮**，具体指**权重（weights）** 和**偏置（bias）** 的数值。一个72B模型就是内部有720亿个这样的数值旋钮。**权重**决定输入的重要性（连接强度），**偏置**决定输出的偏移

**模型 = 架构（计算图结构） + 参数（权重/偏置数值）**，二者分离是只存参数的根本原因：

- 架构是代码实现的，定义了"如何计算"（多少层、多少头、激活函数等），一旦设计好就**固定不变**
- 参数是从训练中学习到的数值，定义了"用什么数值去算"，是唯一随训练变化的部分
- 所以模型文件**只需存储参数**，加载时配合代码架构就能完全复现模型

**参数不是输入进去的，是训练出来的**：

- 训练前：参数为随机数，模型什么都不会
- 训练中：通过反向传播计算梯度，用**梯度下降**反复调整参数
- 训练后：参数固定，所有知识编码在这720亿个数值中
- 推理时：参数被**只读读取**用于计算，不发生变化

**参数中编码了什么信息**：

- **每层权重**决定了输入特征之间的连接强度——浅层学到边缘/纹理等低级特征，深层学到语义概念（人脸、物体部件、句法结构等）
- **偏置**提供了激活阈值偏移，让网络有更多表达能力
- 这些数值本身没有语义，但它们的**整体分布和组合关系**编码了海量训练数据中的统计规律

**推理时用参数就能得到正确结果的本质原因**：

- 训练过程本质上是在做**函数拟合**——让神经网络逼近一个能将任意输入映射到正确输出的复杂函数
- 训练完成的参数就是这个**拟合函数的系数**。就像线性回归确定 ( y=ax+b ) 中的 a 和 b 后，给定 x 就能算出 y
- 推理 = **前向传播**：输入向量逐层与权重矩阵相乘 + 加偏置 + 激活函数 → 逐层变换 → 最终输出
- **通用近似定理**保证：只要有足够多的参数和合适的非线性激活函数，神经网络可以逼近任意复杂函数
- **Scaling Law**进一步证明：参数量越大，拟合的函数越精确，泛化能力越强

**参数的计算**：以LLaMA-3 70B的一个Transformer层为例——自注意力4个投影矩阵各8192×8192（67M/个），FFN两个全连接层各8192×28672（235M/个）+门控层235M，一个层约856M参数，80层约68B，加上嵌入层和输出层≈70B

**参数存储**：72B参数FP32（4字节/个）需要288GB，**FP16/BF16**（2字节/个）需要**144GB**（常用），INT8（1字节/个）需要72GB，INT4（0.5字节/个）需要36GB（量化后）

# 14. 模型训练有哪些阶段和步骤？

**完整训练分为四阶段**：数据准备→预训练→后训练（对齐）→部署优化

**第一阶段：数据准备**

- **数据采集**：Common Crawl（万亿token网页）、Wikipedia（高质量百科\~4B token）、Books/arXiv（书籍论文）、GitHub（代码）、Reddit（对话）
- **数据清洗**：语言过滤→质量过滤（困惑度打分）→精确+模糊去重（MinHash）→安全过滤（PII/有害内容）→启发式规则（太短/符号占比高过滤）。通常砍掉50-70%垃圾
- **Tokenization**：用BPE（字节对编码）分词器将文本转换为数字ID序列。常用V=32K\~128K的词汇表
- **数据混合配比**：不同来源按比例混合，如网页50%+书籍30%+代码15%+学术5%。不同阶段配比可能调整（后20%提高代码+学术比例增强推理）

**第二阶段：预训练（1-3月，万卡集群）**

- **初始化**：权重从正态分布随机初始化，模型是一张白纸
- **损失函数**：**下一个token预测**——模型在每个位置预测下一个token的概率分布，损失=CrossEntropyLoss(预测分布, 真实token)
- **前向传播**：token ID序列→Embedding层（转为向量）→N层Transformer（自注意力+FFN）→LM Head（映射到词汇表概率分布）→计算损失
- **反向传播**：从最后一层逐层往前计算每个参数对损失的梯度（偏导数），利用链式法则传递。**残差连接**使梯度恒为1不衰减，解决梯度消失
- **参数更新**：用**AdamW优化器**更新参数。新参数=旧参数-自适应学习率×动量修正梯度-权重衰减项。AdamW的动量让梯度方向平滑，自适应学习率让高频参数学习慢、低频参数学习快
- **学习率调度**：先预热（小学习率稳住初期不稳定梯度）→余弦衰减（快速下降后精细调整）
- **周期性评估**：每X步检查训练损失（是否下降）、验证损失（是否过拟合）、跑下游benchmark（MMLU/HumanEval/GSM8K）

**第三阶段：后训练/对齐（1-7天）**

- **SFT（指令微调）**：用高质量"指令-回答"对进行监督训练，教会模型遵循指令而非继续写文章。**数据质量>数据数量**——1K条高质量指令比100K低质量数据效果更好
- **RLHF（基于人类反馈的强化学习）**：收集人类偏好数据（对多个回答排序）→训练奖励模型给回答打分→用**PPO算法**更新主模型（最大化奖励+KL散度惩罚防止偏离太远）
- **DPO（直接偏好优化）**：跳过奖励模型，直接用偏好数据更新主模型，效果和RLHF相当但实现更简单。DeepSeek-R1使用的**GRPO**更高效（不需要奖励模型）

**第四阶段：部署优化（可选）**

- **量化**：FP32→INT8/INT4，模型从144GB压缩到36GB，单卡可跑。常用方法：GPTQ、AWQ、GGUF
- **推理优化**：FlashAttention（减少显存读写）、KV Cache、Continuous Batching（提高吞吐）
- **服务化**：分布式部署到多GPU→API上线

**成本估算（72B模型）**：数据准备4-6周（$50K-$200K）；预训练30天512×A100（$3M-$5M）；SFT 1-3天（$20K）；RLHF/DPO 3-7天（$50K）；总计2-3个月，$3M-$6M

# 15. CNN 为什么能识别目标人物？

**核心原理**：CNN**不是"看懂"了目标人物，而是学到了两者在高维像素空间中的数学分界线。** 一张100×100的灰度图是一个10,000维空间中的点，所有目标人物的图片在该空间中聚集成一个区域，非目标人物的图在另一个区域。CNN用720亿个参数编码了这两个区域之间极度扭曲的超曲面边界

**分层特征学习**（目标人物检测为例）：

- **底层**（1-2层）：检测边缘（水平/垂直/对角）、颜色块——所有图像共有，与目标人物无关
- **中层**（3-5层）：检测眼睛形状、嘴巴轮廓、鼻子、皮肤纹理——开始与目标人物相关
- **高层**（6-9层）：检测完整眼睛（眼白+瞳孔+眼皮组合）、完整嘴巴、脸部轮廓、对称分布——明确的人脸部件检测
- **语义层**（10-12层）：检测正面人脸、侧面人脸、戴眼镜人脸、**目标人物**——所有部件组合匹配
- 最后一个全连接层将高层特征映射到二分类输出：目标人物/非目标人物

**关键**：这些特征**不是人设计的，是自动学出来的**。没有任何人告诉模型"眼睛很重要"，而是反向传播发现关注眼睛区域→预测更准确→自动增强眼睛检测器权重

**泛化（为什么能识别没见过的图片）**：模型学的不是"这张具体图片"，而是"目标人物的高维区域边界"。新图片→经过前向传播→落到目标人物区域→输出"目标人物"。只要新图片在训练集覆盖的区域范围内，就能正确识别

**CNN的归纳偏置**：**局部性**（相邻像素有关联）、**平移不变性**（特征位置不重要）、**权值共享**（参数效率极高）。使CNN在中等数据量的图像任务上远优于全连接网络

**非线性层的作用**：每层ReLU激活函数像"折纸"一样扭曲空间。多层非线性使CNN能表达任意复杂的分类边界，完美分开纠缠在一起的不同类别图片

# 16. CNN 为什么能检测涉黄图片？

**核心原理**：**CNN不是"懂"什么是涉黄，而是学到了涉黄图片和正常图片在高维像素空间中的统计分布差异。** 整个过程没有任何人告诉模型"什么是裸体"

**CNN实际上看到的是什么**：

- **底层**：检测到大面积暖色调肤色像素（色相0-30°，中等饱和度亮度）、光滑无衣物褶皱的皮肤纹理、人体曲线边缘（S型曲线）——这些在涉黄图片中统计频率显著高于正常图片
- **中层**：检测到类圆形模式（乳房/臀部轮廓）、水平条状模式（腹部/大腿）、弧形模式（肩膀/腰部曲线）、皮肤+非皮肤边界模式（衣物边缘）——模型**不知道**这些是身体部位，只知道这些形状在涉黄图片中出现更频繁
- **高层**：综合判断"大量肤色区域+弧形边缘+小面积衣物覆盖+特定身体轮廓"的组合概率。同时也会结合沙滩纹理+蓝天+海浪等"正常上下文"特征做区分——这就是为什么穿比基尼的海滩照通常不被判为涉黄

**为何比人工规则好？** 人类规则（如"肤色面积>30%则涉黄"）会被海滩照片误判，也会漏判穿厚衣服的色情图片。CNN同时考虑**数百万个特征组合**（肤色比例×分布模式×边缘曲率×纹理频谱×姿态几何×背景对比度等），没有人类能手动设计这么复杂的判断系统

**CNN的盲点**：

- **假相关**：如果训练集中90%涉黄图片都有粉色背景，模型会认为"粉色=涉黄信号"，导致一张正常粉色背景图被误判。**解决方法**：训练集需要多样化和去偏差
- **不是概念理解**：模型不知道"裸体"这个概念，只知道"这种像素组合的统计模式更接近标签1"。所以人眼看不出的**对抗性攻击**（微调像素）可以骗过模型

**训练过程的本质**：训练前参数随机，两类图片在高维空间中混合无法分开。每步训练通过反向传播调整参数，让**决策边界逐步移动**——发现某类特征有助于区分→增强其权重。经过数百万步迭代，边界精确拟合了"涉黄"的高维区域形状，新图片落在哪一侧就输出对应标签

# 17. 什么是损失函数？为什么需要它？作用是什么？

**损失函数（Loss Function）** 是衡量模型预测结果与真实标签之间差距的函数。数值越小代表模型预测越准。

**为什么需要损失函数**：训练神经网络本质上是一个优化问题——模型参数（权重）→前向传播→预测结果→比对真实值→算出差距=Loss→反向传播（Loss对参数求导）→计算梯度→梯度下降更新参数→重新预测→Loss更小。**如果没有损失函数，模型不知道自己做得好不好，也不知道该往哪调参。** 类比：损失函数=考试分数，模型=学生，梯度下降=根据错题针对性复习

**核心作用**：

| 作用 | 说明 |
| --- | --- |
| **量化误差** | 把"预测得好不好"变成一个数值，可比较、可优化 |
| **提供梯度信号** | Loss对参数求导→梯度→告诉参数该往哪调 |
| **驱动学习** | 梯度下降=沿着Loss减小的方向更新参数 |
| **约束模型行为** | 不同Loss设计让模型学会不同东西 |

**常见损失函数**：

| 任务 | Loss | 作用 |
| --- | --- | --- |
| 分类 | **Cross-Entropy Loss（交叉熵）** | 衡量预测分布与真实分布的差距 |
| 回归 | **MSE（均方误差）** | 预测值和真实值的平方差 |
| 人脸识别 | **ArcFace Loss（加性角度间隔）** | 在角度空间拉近同类、推开异类 |
| 目标检测 | **CIoU Loss + BCE** | Box回归+分类 |
| 扩散模型 | **L2 Loss（预测噪声）** | 扩散模型预测噪声残差 |

**一句话总结**：损失函数是模型的"裁判"，告诉模型做得对还是错、差了多少、该往哪个方向改。没有损失函数就没有梯度下降，也就没有深度学习。

# 18. 图片分类和目标检测的主流模型有哪些？有什么特点和怎么选？

**图片分类——主流模型**：

| 模型 | 年份 | 特点 | 适合场景 |
| --- | --- | --- | --- |
| **ResNet** | 2015 | 残差连接，经典稳定 | 学术基准、特征提取骨干、工业遗留系统 |
| **EfficientNet** | 2019 | NAS搜索最佳缩放，精度/效率平衡 | 移动端、云端推理 |
| **ConvNeXt** | 2022 | 现代CNN，借鉴Transformer技巧，精度好部署容易 | 视觉任务通用骨干 |
| **ViT (Vision Transformer)** | 2020 | 纯Transformer，大数据下超越CNN | 超大数据集（百万级+），精度上限高 |
| **DeiT** | 2021 | ViT数据高效版 | 不需要海量数据的ViT方案 |
| **Swin Transformer** | 2021 | 层次化窗口注意力 | 密集预测任务（检测/分割）的Transformer骨干 |
| **MobileNet** | 2017 | 深度可分离卷积，轻量 | 手机/嵌入式/边缘设备 |

**分类选型**：

| 条件 | 推荐 |
| --- | --- |
| 数据量大（百万级+） | ViT / Swin |
| 数据中等，需要落地 | ConvNeXt / EfficientNet |
| 移动端/边缘设备 | EfficientNet-Lite / MobileNet |
| 学术基准/对比实验 | ResNet（经典基线） |
| 需要做检测/分割下游 | ConvNeXt / Swin（作backbone） |

**目标检测——主流模型**：

**两阶段（Two-Stage）——慢但准**：

| 模型 | 特点 | 适合场景 |
| --- | --- | --- |
| **Faster R-CNN** | RPN生成proposals再分类 | 学术基准、精度优先 |
| **Mask R-CNN** | 加分割分支 | 同时做检测+实例分割 |
| **Cascade R-CNN** | 级联IoU阈值，质量逐步提升 | 高精度检测 |

**单阶段（One-Stage）——快**：

| 模型 | 特点 | 适合场景 |
| --- | --- | --- |
| **YOLOv8/v9/v10/v11** | 实时检测王者，生态最好，持续迭代 | **工业首选**，视频监控、自动驾驶、边缘设备 |
| **YOLOv8** | Ultralytics维护最稳定 | 产品落地、工程部署 |
| **YOLOv10** | NMS-free端到端，推理更快 | 速度和精度都要 |
| **RT-DETR** | 实时端到端Transformer检测 | 不想用Anchor/NMS的实时检测 |

**Transformer端到端**：

| 模型 | 特点 | 适合场景 |
| --- | --- | --- |
| **DETR** | 首个Transformer端到端，无Anchor/NMS | 学术研究、简化pipeline |
| **Deformable DETR** | 可变形注意力，收敛快 | 实用化DETR |
| **DINO DETR** | SOTA端到端检测 | 追求最高精度 |

**检测选型**：

| 需求 | 推荐 |
| --- | --- |
| **工业落地、实时推理** | YOLOv8（最稳妥）→ YOLOv10（更新） |
| **边缘设备/手机** | YOLOv8-nano / YOLOv8-tiny / NanoDet |
| **最高精度** | Cascade R-CNN / DINO DETR |
| **同时做分割** | Mask R-CNN / YOLOv8-seg |
| **不想碰Anchor/NMS** | DETR / RT-DETR |
| **零样本分割** | SAM（Segment Anything） |

**选型决策树**：

```
你要做什么？
│
├─ 图片分类
│  ├─ 大数据量(百万+) → ViT / Swin
│  └─ 普通数据量 → ConvNeXt / EfficientNet
│
├─ 目标检测
│  ├─ 实时/FPS优先 → YOLO系列
│  ├─ 精度优先 → Cascade R-CNN / DINO DETR
│  └─ 端到端省事 → DETR / RT-DETR
│
├─ 实例分割 → Mask R-CNN / YOLOv8-seg
│
└─ 零样本分割 → SAM
```

**一句话总结**：分类无脑ConvNeXt（稳妥）或ViT（上限高），检测无脑YOLOv8/10（工业标准），精度压榨就上DINO DETR。

# 19. 人脸识别的主流模型有哪些？原理是什么？

**人脸识别的三步骤**：**检测人脸 → 提取特征向量（Embedding） → 比对相似度**

核心思路：把一张人脸映射到一个向量，让同一个人不同照片的向量距离近，不同人的距离远。

**特征提取模型（主流）**：

| 模型 | 年份 | 骨干网络 | Loss函数 | 特点 | 适合场景 |
| --- | --- | --- | --- | --- | --- |
| **FaceNet** | 2015 | Inception/ResNet | Triplet Loss | 开山之作，三元组训练 | 学术基线 |
| **ArcFace** | 2018 | ResNet-100 | **ArcFace Loss（加性角度间隔）** | **工业标准**，LFW 99.83% | 门禁、金融、安防 |
| **CosFace** | 2018 | ResNet | CosFace Loss（余弦间隔） | 与ArcFace类似 | 同场景备选 |
| **MagFace** | 2021 | ResNet-100 | MagFace Loss | 动态间隔+质量评价 | 质量分+识别一体化 |
| **AdaFace** | 2022 | ResNet | 自适应margin | 低质量/模糊人脸效果好 | 监控、非受控场景 |
| **TransFace** | 2023 | ViT | ViT+ArcFace | Transformer做骨干 | 大规模数据集 |

**Loss函数演化**：Softmax Loss（基础）→ Center Loss（加类内约束）→ Triplet Loss（三元组）→ SphereFace（角度margin）→ CosFace（余弦margin）→ **ArcFace（角度margin，最稳主流）** → MagFace（动态margin+质量）→ AdaFace（自适应低质量）

**检测部分（前置步骤）**：

| 模型 | 特点 | 适合场景 |
| --- | --- | --- |
| **MTCNN** | 经典三段级联，慢但准 | 小批量、高精度 |
| **RetinaFace** | SOTA，带关键点回归 | 多数场景首选 |
| **YOLOv8-face** | 实时、轻量 | 视频流、边缘设备 |
| **SCRFD** | 计算量小，速度快 | 移动端、嵌入式 |

**人脸对齐（关键点检测）**：**MTCNN**（自带5点）、**PFLD**（轻量98点）、**FAN**（高精度2D/3D）、**InsightFace 2D106**（106点最全）

**常见场景选型**：

| 场景 | 识别模型 | 检测模型 | 说明 |
| --- | --- | --- | --- |
| **门禁/考勤** | ArcFace-R50 | RetinaFace | 受控光照，正脸为主 |
| **移动端/手机解锁** | MobileFaceNet+ArcFace | SCRFD | 轻量，FPS>30 |
| **安防监控** | AdaFace+ViT | RetinaFace | 低质量、大角度、遮挡多 |
| **金融KYC** | ArcFace-R100 | RetinaFace | 精度第一 |
| **百万级底库检索** | ArcFace-R100+向量库 | RetinaFace | 需要FAISS/Milvus |
| **无约束网络人脸** | MagFace/AdaFace | RetinaFace | 各种自拍、模糊、暗光 |

**工业首选路线**：**ArcFace + ResNet-100 + RetinaFace**。ArcFace稳了7年，学术工业共同认可；ResNet-100是精度/算力的黄金平衡；RetinaFace检测精度最高。InsightFace库集成了全套。

# 20. 图片分类和目标检测模型训练的关键参数与优化方法

**图片分类——关键参数**：

**学习率（LR）**：初始3e-4（AdamW）或0.1×batch_size/256（SGD）。策略推荐**Cosine Annealing**+**Linear Warmup**（前5-10个epoch从0线性升到初始LR）

**Batch Size**：推荐64-1024。大batch→梯度更稳定→可适当加大LR。小batch（16-32）→BN统计不准→需更小LR

**优化器**：SGD+Momentum（0.9）收敛好泛化强（CV传统）；**AdamW（推荐）** 省心自带自适应，适合ViT/ConvNeXt。目前趋势AdamW > SGD

**权重衰减（Weight Decay）**：ResNet/ConvNeXt用1e-4\~5e-4；ViT/Swin用0.01\~0.1（Transformer需要更强正则化）。规律：Transformer > CNN

**数据增强（分类效果提升最大）**：

- 基础：RandomResizedCrop + RandomHorizontalFlip
- 进阶：**RandAugment / AutoAugment + MixUp + CutMix**（涨点2-5%甚至更多）

**标签平滑（Label Smoothing）**：值0.1默认，防止过度自信，提升泛化

**Dropout / Stochastic Depth**：ViT用Dropout=0.1、Stoch.Depth=0.1\~0.4；CNN通常不需要或极小

**训练epochs**：小数据集（CIFAR）200-300；ImageNet级别90-300

**目标检测（YOLO系列，以YOLOv8为例）——核心参数**：

```
model: yolov8n/s/m/l/x（模型大小）
epochs: 100-300（越多不一定越好，配合早停）
patience: 50（早停）
batch: 16-64（看显存）
imgsz: 640（标准）/ 1280（小目标）
optimizer: AdamW（推荐）或 SGD
lr0: 0.01（SGD）或 0.001（AdamW）
lrf: 0.01（最终LR = lr0 × lrf）
momentum: 0.937
weight_decay: 5e-4
warmup_epochs: 3
warmup_momentum: 0.8
warmup_bias_lr: 0.1
```

**YOLO数据增强（自动集成可调）**：

```
hsv_h: 0.015（色相偏移）
hsv_s: 0.7（饱和度）
hsv_v: 0.4（明度）
degrees: 0.0（旋转，0-45度）
translate: 0.1（平移）
scale: 0.5（缩放）
fliplr: 0.5（左右翻转）
mosaic: 1.0（**马赛克增强，小目标关键！**）
mixup: 0.0（大模型时可开启）
```

**YOLO调优秘诀**：

- **Mosaic增强**对小目标效果提升巨大，但最后10个epoch建议关掉（避免分布偏移）
- **YOLOv8+是Anchor-free**，省去调Anchor的麻烦
- **小目标**→imgsz=1280，加小检测头
- **类别不平衡**→调整cls_pw（类别权重）
- **过拟合**→降低epochs、加dropout、关mosaic

**通用调优策略**：

**1. 先过拟合一个小样本集（验证代码正确性）**：取100-1000张图，训练到train_loss≈0。如果不能过拟合→代码/数据有问题

**2. LR找最优（LR Range Test）**：从1e-7到1，看loss下降最快的区间。典型范围：3e-4\~1e-3（AdamW）

**3. Batch Size与LR联动**：`LR = base_LR × (batch_size / 256)`。base_LR：SGD=0.1，AdamW=3e-4

**4. 数据增强永远第一优先级**：分类用RandAugment+MixUp+CutMix；检测用Mosaic+多尺度训练

**5. EMA（指数移动平均）**：模型参数指数平均，推理时用。分类涨0.5-1%，检测涨0.5-2%

**6. 梯度裁剪**：`max_norm=1.0`（检测常用）；NLP常用，CV一般不必须

**快速调试检查表**：

| 现象 | 可能原因 | 解决 |
| --- | --- | --- |
| Loss不下降 | LR太小/数据未归一化 | 调LR/检查预处理 |
| Loss直接Nan | LR太大/梯度爆炸 | 降低LR/梯度裁剪 |
| 训练过拟合 | 增强不足/epochs太多 | 加增强/早停/降epochs |
| 验证集与训练集差距大 | 过拟合 | 加增强/加WD/Dropout |
| 小目标检测差 | 分辨率低/增强不够 | 提imgsz/开Mosaic |
| mAP低但loss低 | 过拟合了 | 加增强/早停 |

**一句话总结**：分类看数据增强，检测看分辨率+Mosaic，两个都先做LR Range Test确定学习率，然后用Cosine+AdamW省心省力。

# 21. 深度学习各模型架构有哪些代表性算法？各有什么特点？

| **DenseNet**（2017） | 密集连接，极致特征复用 | 小数据集、医学图像 |

**算法发展脉络总结**：

- **CNN演进**：LeNet→AlexNet（引爆DL）→VGG（深而简洁）→ResNet（残差连接突破）→MobileNet（轻量化）→EfficientNet（NAS自动缩放）→ConvNeXt（融合Transformer优点）
- **Transformer演进**：原始Transformer（机器翻译）→BERT（双向理解）→GPT（解码器生成）→ViT（视觉）→多模态统一。模型越做越大，GPT-3→GPT-4→LLaMA→DeepSeek

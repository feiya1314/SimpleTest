**一、先说下 ThreadPoolExecutor 的基本原理**：
1\. 当提交一个任务时，如果线程数没有达到coreSize，那么就会新建一个线程，并绑定该任务，直到数量到达
coreSize前都不会重用之前的线程
2.到达后，提交的任务都会放到一个等待队列中进行等待，线程池中的**线程会使用take()阻塞的从等待**队列拿任务
3.当队列有界，并且线程不能及时取走队列中的任务，等待队列有可能会满，那么线程池将会创建临时线程来执行
任务
4.临时线程 通过poll(keepAliveTime，timeUnit)来执行任务，如果到了keepAliveTime还取不到，那么会被回收
掉，临时线程的数量不能大于 maxPoolSize - coreSize
5.当线程数到达maxSize后，将会执行拒绝策略RejectedExecutionHandler，包括抛异常，静默拒绝，抛弃最old
任务，使用原远程执行等策略知道了原理你大概就知道线程被如何管理了当一个task执行完，如果线程数小于
coreSize，那么这个线程就会一直存在线程池中，如果是临时线程，在等待keepAliveTime后，将会被回收掉

**二、线程池线程状态**
1、**RUNNING**： 可以接收新的 task 并且 处理队列中的 task
2、**SHUTDOWN**：不再接收新的 task 但是继续处理队列中的 task
3、**STOP** ：不再接收新的 task 并且不再处理队列中的 task，并且 interrupt 正在进行的 task
4、**TIDYING** ： 所有的 task 已经终止 ，workerCount为 0，线程转变为状态 TIDYING ，之后将执行
terminated() 方法
5、**TERMINATED** ：terminated() 方法执行完

**三、状态转换**
RUNNING -\> SHUTDOWN ： 调用 shutdown() 方法，或许隐式调用 finalize()
(RUNNING or SHUTDOWN) -\> STOP ： 调用shutdownNow()方法
SHUTDOWN -\> TIDYING ：当 队列 和 pool 都是 空的时候
STOP -\> TIDYING ：当 pool 是空的时候
TIDYING -\> TERMINATED ： 当 terminated() 方法完成时

4、addWorker 方法用于添加 worker 线程。
==增加线程是通过线程池中的addWorker方法==，该方==法的功能就是增加一个线程，==该方法不考虑线程池是在哪个阶段增加的该线程，这个分配线程的策略是在上个步骤完成的，==该步骤仅仅完成增加线程，并使它运行，==最后返回是否成功这个结果。
addWorker方法有两个参数：firstTask、core。
firstTask参数用于指定新增的线程执行的第一个任务，该参数可以为空；
core参数为true表示在新增线程时会判断当前活动线程数是否少于corePoolSize，false表示新增线程前需要判断当前活动线程数是否少于maximumPoolSize，

线程池关闭的过程：
<span style='color:black'>二、调用 shutdown () 完整关闭流程</span>
<span style='color:black'>步骤 1：CAS 修改线程池状态</span>
<span style='color:black'>从 **RUNNING → SHUTDOWN**</span>
<span style='color:black'>步骤 2：停止接收新任务</span>
<span style='color:black'>后续 execute/submit 直接触发**拒绝策略**。</span>
<span style='color:black'>步骤 3：中断**空闲线程**（不是全部线程）</span>
<span style='color:black'>遍历工作线程：</span>
- <span style='color:black'>**正在干活的核心 / 非核心线程**：**不中断**，让它把当前任务跑完</span>
- <span style='color:black'>**阻塞在队列 getTask () 上的空闲线程**：**发中断**，唤醒退出</span>
<span style='color:black'>步骤 4：继续执行 **阻塞队列里剩余所有任务**</span>
<span style='color:black'>SHUTDOWN 状态下：</span>
<span style='color:black'>工作线程会**持续从队列取任务执行**，直到队列清空。</span>
<span style='color:black'>步骤 5：队列空了 → 工作线程逐个消亡</span>
- <span style='color:black'>线程从队列取不到任务，退出循环</span>
- <span style='color:black'>工作线程一个个自然结束</span>
<span style='color:black'>步骤 6：所有线程消亡 → 进入 TIDYING</span>
<span style='color:black'>线程数为 0，触发钩子 terminated()</span>
<span style='color:black'>步骤 7：最终切换为 TERMINATED 彻底终止</span>
<span style='color:black'>线程池完全关闭。</span>

<span style='color:black'>三、对比：shutdownNow () 关闭流程</span>
1.  <span style='color:black'>状态 CAS：**RUNNING → STOP**</span>
2.  <span style='color:black'>拒绝新任务</span>
3.  <span style='color:black'>**中断所有正在执行的工作线程**</span>
4.  <span style='color:black'>**不再执行队列剩余任务**，把未执行任务**返回**</span>
5.  <span style='color:black'>直接过渡到 TIDYING → TERMINATED</span>

**标准优雅关闭流程**

- <span style='color:black'>调用 shutdown() 拒绝新任务</span>
- <span style='color:black'>循环 + awaitTermination 阻塞等待任务跑完</span>
- <span style='color:black'>超时未关闭 → 降级 shutdownNow() 强制中断</span>
- <span style='color:black'>捕获中断异常、恢复中断位</span>

- <span style='color:black'>**shutdown()**：**优雅开始关闭**</span>
  - <span style='color:black'>不再接受新任务</span>
  - <span style='color:black'>已提交的任务（队列里 + 正在执行）**全部执行完**</span>
- <span style='color:black'>**shutdownNow()**：**暴力关闭**</span>
  - <span style='color:black'>不再接受新任务</span>
  - <span style='color:black'>尝试中断**正在运行**的任务</span>
  - <span style='color:black'>直接丢弃队列中未执行任务，返回未执行任务列表</span>
- <span style='color:black'>**awaitTermination**：**阻塞等待收尾**，配合 shutdown 实现完美优雅关闭</span>
